# Useful Tools

These are common tools for medical-image projects. Choose only what your project actually needs.

## Python

- NumPy / SciPy — numerical processing
- Matplotlib — visualization
- scikit-image — image processing
- scikit-learn — classical machine learning
- OpenCV — computer vision utilities
- PyTorch — deep learning
- MONAI — medical-imaging deep learning workflows
- NiBabel — NIfTI neuroimaging files
- SimpleITK — medical image I/O, filtering and registration
- pydicom — DICOM access

## MATLAB

The course assignments use MATLAB. Useful areas include:

- Image Processing Toolbox
- matrix/image manipulation
- filtering
- edge detection
- segmentation
- registration

## Reproducibility

Record package versions and random seeds when relevant. Prefer a `requirements.txt`, `environment.yml`, or another environment file so results can be reproduced.
